# MisterMarqueePackBuilder
This script makes it easier for MisterFPGA users looking to create a marquee pack for TTY2RPI.

The images I recommend are from Launchbox:
https://forums.launchbox-app.com/files/file/3080-huge-mame-marquee-collection-including-many-in-4k-resolution/

I am using TTY2RPI (https://github.com/ojaksch/MiSTer_tty2rpi)
